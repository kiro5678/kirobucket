## Known compatibility and dependency checks

- **IPMI Tool GUI** depends on the external `ipmitool` utility; the author also documents plaintext password storage in its host configuration.
- **sSpeedtest** requires the separate Ookla Speedtest CLI.
- **sWeather** uses the legacy Yahoo Weather API; current service compatibility must be checked.
- **sLyrics** uses the ChartLyrics API; current service availability must be checked.
- **SubAHK** requires a running compatible Subsonic server and is limited to playlist management.
- **SigcheckGUI**, **PDFInfoGUI**, and **tiffInfoGUI** are front-ends that need separate command-line utilities.
- **Sensatronics Tray Tool** is useful only with supported Sensatronics E4/U16 hardware.
- **Files 2 Folder** is a Windows shell extension and requires system registration; it is not a normal portable application.
- **sImgurUploader** requires a user-provided Imgur API key.
- **Wallpaper Welder** is documented by its author as not working on Windows 8/10.
- **Boot Snooze** and **File Bucket** are documented for Windows XP; several other older programs were tested only on Windows 7. Compatibility with Windows 10/11 needs testing.
