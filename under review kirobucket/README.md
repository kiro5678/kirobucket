# KiroBucket — Review documentation

This directory is retained for its documentation and the protected placeholder file. JSON manifest files are not stored here.

The 98 legacy JSON manifests formerly staged in this directory have been moved into `bucket/` without changing their contents. Their outstanding verification notes are maintained in [Review before classifying](../docs/manifest-portability.md#review-before-classifying).

Do not create new JSON manifest files in this directory. Add review status and supporting evidence to `docs/manifest-portability.md` instead.
