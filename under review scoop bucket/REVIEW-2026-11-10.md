## Verification

Candidates that do not currently have a suitable, version-pinned Windows package are documented in [docs/unavailable-manifest-candidates.md](../docs/unavailable-manifest-candidates.md). No placeholder JSON manifest is kept under review for those candidates.

PR #99 archive validation checked 18 manifests, including `bucket/filebrowser.json` and `bucket/voicestudio.json`, and reported zero failures. File Browser's official release SHA-256 matched and its declared `filebrowser.exe` path was present. VoiceStudio's NSIS container was extracted, its nested `app-64.7z` payload was extracted into a simulated Scoop directory (869 files), and `VoiceStudio.exe` was found at the declared root path.

After merge, master archive validation passed; File Browser Checkver passed in both PowerShell and PowerShell 7, and its automatic-update path was exercised with zero failures. These checks do not constitute a live GUI launch or a complete Scoop install/update/uninstall lifecycle test.

The standalone BoilR executable was recognized without misclassifying it as a 7-Zip archive.

The official bucket is not duplicated with staging copies from this review. Candidates without a current Scoop-ready package are documented separately; they are not represented by incomplete manifest JSON files.
