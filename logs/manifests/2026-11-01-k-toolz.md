# K-Toolz manifest — 2026-11-01

## Added

- `bucket/k-toolz.json` — K-Toolz 4.0.2, official 64-bit NSIS setup asset. Pins the GitHub Release SHA-256 digest and uses `#/dl.7z` to extract the payload without running the NSIS installer.
- Uses the official GitHub Releases API for `checkver` and a versioned release-asset template for `autoupdate`.
- Declares `k-toolz.exe` as the shim and Start Menu shortcut target. The Windows archive validator confirmed that this executable exists at the archive root.

## Portability classification

- Classified **Nonportable**, not Portable or Review. The app's normal startup code unconditionally registers `ktoolz://` and legacy `lumora://` protocol handlers under HKCU. This is persistent Windows integration, matching the existing bucket rule used for applications such as Nook.
- Scoop does not execute the NSIS installer. Optional WebView2 and Visual C++ prerequisites are not installed by this manifest.
- PawnIO and ViGEmBus are optional drivers installed only after in-app user actions; Scoop does not install or remove them.
- PlainOSD, network statistics, and StutterHunter can create elevated Task Scheduler tasks after an explicit UAC confirmation. Those tasks are not created by Scoop and may remain after uninstall; remove them from Task Scheduler if no longer needed.
- Application settings and game-library data remain under `%APPDATA%\\K-Toolz`; the WebView2 profile remains under `%LOCALAPPDATA%\\K-Toolz\\WebView2`.
- The guarded `pre_uninstall` hook removes URL protocol and autostart registrations only when they still point inside this Scoop app root. Scoop also invokes `pre_uninstall` during upgrades, so launch K-Toolz once after updating to restore those app-managed entries and the saved autostart preference.
